# 参数单位与缺省规则

- 仿真时长及 `TimeValue`：省略单位按秒，支持 `ms/us/µs/μs/ns` 等时间单位。仿真时长必填；协议属性留空使用注册默认，节点覆盖留空继承统一值。
- `DataRateValue`：省略单位按 bit/s；`bps`、`bit/s`、`kbps`、`Mbps`、`B/s` 等统一转换。`b` 为比特、`B` 为字节，大小写不混同。
- 数值属性：单位来自实际注册 help 的明确单位说明（如 `(m)`、`(seconds)`、`in meters.`），或可选 `[unit=m]` 声明。省略单位保持注册原单位；例如 Frequency 的原单位是 kHz，`25000Hz` 转为 `25`。
- 注册信息缺失或冲突时不推断单位。此类数值仅接受纯数字；最终取值范围由实际 ns-3 AttributeChecker 检查。中文辅助标签不参与换算规则。
- 未来协议可以通过注册 help 的 `[unit=...]` 明确单位，无需增加协议名称分支。Vector3DValue 只有声明单位后才对 `x:y:z` 分量换算。
- 坐标、显示范围半径支持 `m/km/cm/mm`，省略单位按 m。坐标保存为数值米；显示半径保留用户输入；范围圈空值继续使用所选 PHY 的有效传播范围。回放传播速度省略单位按 m/s，并支持 km/s。
- 空白覆盖按层级忽略；`0` 是显式值，不等于留空。无效非空输入显示错误，不自动换成默认值。整数参数不截断小数，科学计数统一转换，换算不可安全表示的大整数拒绝。
- 实验 JSON 保留原输入，导入不改写配置。统一校验与生成流程使用相同单位解析；运行时将转换结果交给实际 AttributeChecker。

校验：`yarn check:regressions`；真实仿真：先预编译，再执行 `node scripts/smoke-parameter-units.mjs`（复用 dev 服务，不修改浏览器草稿）。

时间轴按日志时长与精度固定当前时间的占位宽度，数字位数、末尾零和 μs/ms/s 切换不再挤动滑轨；仍保留日志小数微秒精度。
